# ESPoCRM Contact Atelier — Web UI v3

Python + Flask interface over the existing EspoCRM API layer.

Run:
1. pip install -r requirements_web.txt
2. python web_app.py
3. Open http://127.0.0.1:5000

The desktop Tkinter application is intentionally left untouched. This web UI is a separate frontend experiment using the same API layer.
